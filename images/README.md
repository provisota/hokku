# Иллюстрации

Сохраняйте файлы PNG в этой папке с расширением `.png` и именами в нижнем регистре.

| Страница | Имя файла |
| --- | --- |
| Общая обложка | `cover.png` |
| Хроника | `album-chronicle.png` |
| Весна | `album-spring.png` |
| Лето | `album-summer.png` |
| Осень | `album-autumn.png` |
| Зима | `album-winter.png` |
| Красота | `album-beauty.png` |
| Хокку `hokku-6` | `image-6.png` |

ID стихотворений перечислены в [hokku-list.txt](../hokku-list.txt). Одна картинка показывается в обоих альбомах, где есть это хокку. После добавления файла откройте нужную страницу или обновите её в браузере. Если файл отсутствует или повреждён, книга сохраняет заглушку или оформление общей обложки.
