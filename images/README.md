# Иллюстрации

Сохраняйте файлы WebP в этой папке с расширением `.webp` и именами в нижнем регистре.

| Страница | Имя файла |
| --- | --- |
| Общая обложка | `cover.webp` |
| Хроника | `album-chronicle.webp` |
| Весна | `album-spring.webp` |
| Лето | `album-summer.webp` |
| Осень | `album-autumn.webp` |
| Зима | `album-winter.webp` |
| Красота | `album-beauty.webp` |
| Хокку `hokku-N` | `image-N.webp` |
| Общая заглушка | `placeholder.webp` |

ID стихотворений перечислены в [hokku-list.txt](../hokku-list.txt). Например, для `hokku-6` нужен файл `image-6.webp`. Одна картинка показывается во всех альбомах, где есть это хокку. После добавления файла откройте нужную страницу или обновите её в браузере.

Если изображение отсутствует или повреждено, книга показывает `placeholder.webp`. Если и этот файл недоступен, на развороте появляется встроенная заглушка, а общая обложка использует CSS-оформление.
