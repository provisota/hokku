# Предложение по сборнику хокку

## Why

Хокку хранятся в трёх исходных файлах. Сборник в формате книги позволит читать их по альбомам и постепенно добавлять иллюстрации к уже опубликованным стихам.

## What Changes

- **Фаза 1. Сборник без изображений.** Распределить все хокку по шести альбомам из `ideas/ideas.md`, сохранить исходные строки и вынести даты и примечания в отдельный блок. Собрать статическую книгу с общей обложкой, оглавлением на первом развороте и титульными разворотами альбомов. Предусмотреть сквозное листание, счётчик страниц и возврат на обложку.
- **Фаза 2. Иллюстрации.** Добавить изображения в традиционном японском стиле для общей обложки, титульных разворотов альбомов и каждого хокку. Привязать их к постоянным идентификаторам и сохранить заглушки для отсутствующих изображений.

## Capabilities

### New Capabilities

- `hokku-catalog` — сохранение исходных хокку, их идентификация и распределение по альбомам.
- `book-reader` — чтение статической книги, навигация по разворотам и показ иллюстраций.

### Modified Capabilities

## Impact

- Источник сборника — `raw-sources/`. Оформление и навигация следуют финальному прототипу «Книга» из `prototypes/index.html`.
- Сайт состоит из статических файлов и работает без серверной логики.
