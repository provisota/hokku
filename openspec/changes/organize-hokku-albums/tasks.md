# Задачи

## 1. Фаза 1. Сборник без изображений

- [x] 1.1 Перенести все хокку из трёх файлов в каталог, присвоить постоянные идентификаторы и сохранить даты, время и примечания отдельно. Сверить число записей и каждую строку, дату и пометку с оригиналом.
- [x] 1.2 Собрать «Хронику». Проверить, что в ней есть каждый идентификатор ровно один раз, датированные хокку идут по возрастанию даты и времени, а недатированные сохраняют порядок исходников.
- [x] 1.3 Распределить записи по четырём сезонным альбомам и «Красоте». Проверить, что у каждого хокку ровно один тематический альбом и что спорные случаи сверены с контекстом и датой.
- [x] 1.4 Собрать книгу с общей CSS-обложкой, оглавлением на первом развороте, титулами альбомов и разворотами хокку. В браузере сверить высоту обложки и разворотов, центрирование названия на левой странице, заглушку на правой и переходы из оглавления ко всем шести титулам.
- [x] 1.5 Реализовать нижние стрелки, сквозной счётчик от обложки и кнопку «Оглавление ↑». Проверить эквивалентность кнопок и клавиш `←`, `→` и `↑`, переход через границу альбомов, крайние страницы, прямые ссылки и историю браузера.
- [x] 1.6 Выбрать читаемый кириллический шрифт с каллиграфической стилизацией и реализовать подгонку кегля. Проверить самые длинные строки на широком и узком экранах, сохранность авторских переносов и отдельный блок даты и примечаний.

## 2. Фаза 2. Добавление изображений

- [ ] 2.1 Подготовить в традиционном японском стиле изображение для общей обложки и по одному для правой страницы каждого из шести титульных разворотов. Проверить читаемость названия книги и соответствие каждой иллюстрации своему альбому.
- [ ] 2.2 Подготовить по одной иллюстрации к каждому хокку, добавить альтернативные описания и связать файлы с постоянными идентификаторами. Сверить каждую иллюстрацию с текстом и убедиться, что все ссылки указывают на существующие файлы.
- [x] 2.3 Подключить WebP в книге и проверить одинаковое отображение хокку в «Хронике» и тематическом альбоме. При отсутствии изображения или ошибке загрузки проверить показ `placeholder.webp`. При недоступности заглушки проверить CSS-оформление обложки и встроенную заглушку на разворотах.
